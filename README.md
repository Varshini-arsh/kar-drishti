# Pragya · Insight for every tax desk (online demo)

Public demo of Pragya, a multi-agent assistant for Indian Income Tax officers.
All data is synthetic and the circulars are fictitious. Uploads from visitors' computers are turned off;
visitors add the built-in synthetic datasets with **+ Add data**, and anything they add stays private to their visit.
AI wording comes from Groq (cloud) when a key is set in the app's Secrets; detection, scores and every number
come from code. The full version runs entirely on the officer's own computer with a local model (Ollama).
